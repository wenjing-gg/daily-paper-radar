# 先核实来源，再分析论文

这是可选的个人阅读门槛，不是论文质量认证或 AI 写作检测器。公开模板默认关闭；开启后，在生成完整摘要之前执行以下流程：

1. 来源抓取、关键词匹配与已推论文去重。
2. 读取 HTML 作者栏，匹配第一位作者的机构，不能把其他作者机构直接算给一作。
3. HTML 无机构时，可下载 PDF 并读取首页，请模型只识别作者与机构上标对应关系。返回机构名和原文引文需在首页文本中出现；保存证据和 PDF 页码链接。不根据作者姓名或常识猜单位。
4. 一作至少一个机构属于 QS 综合排名前100，或命中明确配置的研究团队白名单，才通过来源门槛。
5. 无法确认机构、独立研究者、名单外学校与团队排除；有代码链接的来源合格论文优先。默认无代码链接仍可保留。
6. 通过门槛后才调用模型生成方法摘要、证据与局限分析；HF 候选配额在机构筛选之后应用。

“个人发的”按无合格机构的独立研究处理，不按作者人数或 HF 投稿账号判断。一个作者但有合格机构的论文可以通过；一作多个机构中任何一个达标即可通过，普通合作者在名校不构成放行依据。PDF 上标关系由模型识别仍可能出错，可根据留存引文复核。

## GitHub 配置

在仓库 Actions Variables 中设置：

| 名称 | 推荐值 | 作用 |
| --- | --- | --- |
| `SOURCE_GATE_ENABLED` | `true` | 开启来源准入 |
| `MAX_QS_RANK` | `100` | 排名上限，支持1–100 |
| `UNKNOWN_INSTITUTION_POLICY` | `reject` | 无法核实机构时排除；`keep` 可放宽 |
| `CODE_POLICY` | `prefer` | 有代码优先；`required` 要求发现仓库链接；`off` 不按代码排序 |
| `PDF_AFFILIATION_FALLBACK` | `true` | HTML 不足时识别 PDF 首页机构 |
| `MAX_METADATA_CANDIDATES` | `100` | 每批最多核查多少篇，支持1–500，超预算单独记账，不伪称已审核 |
| `PAPER_METADATA_ENABLED` | `true` | 启用作者栏信息抓取，来源筛选依赖此项 |

PDF 机构识别使用已有三项 LLM 配置和低峰保护，只读取首页文本，但仍有少量模型费用。已成功识别的一作机构会缓存；完整摘要仅为通过名单的论文生成。云端自动安装 PDF 解析依赖。

本地在 `config/profile.json` 修改 `source_gate`；PDF 回退需要 API 后端和 `python -m pip install -r requirements.txt`。CLI 用户可仅开启 HTML 筛选，或另行配置 API 做首页识别。

## 排名与团队名单

- [config/qs_top100.json](../config/qs_top100.json)：QS **2027 世界大学综合排名**快照，2026-09-29 核对，排名截至100，含并列共102所。来源为 [QS 官方排名](https://www.qs-topuniversities.cn/en/university-rankings/world-university-rankings/2027)。不是计算机学科排名，不自动跟随每年新版变更。
- [config/trusted_teams.json](../config/trusted_teams.json)：可编辑团队名称与别名白名单。初始包含 OpenAI、Anthropic、Google/DeepMind、Meta、Microsoft、NVIDIA、Apple、Amazon、DeepSeek、阿里、腾讯、字节、华为、百度、上海AI实验室、北京智源。这是订阅配置，不是权威“知名度”排名。
- 学校与团队别名只在已提取的机构文本中匹配，不搜索摘要或参考文献。补别名需核实官方名称，不能用含义不明的短词或泛化校名。例如不能把加州大学所有分校一并归为伯克利。
- 更新年份时先核实 QS 官方结果，修改快照年份、来源和名次，再测试。文件只存排名事实和匹配别名；QS 数据的权利属于其权利人，MIT 不对第三方数据授予额外权利。

## 如何查看筛选结果

`state/output/raw_papers.json` 的 `source_gate` 包含每篇 ID、准入/排除原因、命中机构、QS 年份与名次、作者栏来源及代码链接状态。GitHub 可下载最新 `radar-state` 查看；不会把排除列表塞进群日报。

未通过的论文不会传给完整摘要模型，也不会写入“已成功推送”记录。下次来源信息补齐后仍有机会重新核查。`reissue` 会重新按当前门槛筛选保存的候选；`resend_bot` 只是重发历史日报，不改变历史筛选结果。若需要更换规则并重做内容，使用 `reissue` 而非 `resend_bot`。

## 信息边界

无法获取 PDF、PDF 超过15MB、扫描件无文本、作者上标在文本提取时丢失，仍可能无法核实机构；严格模式会排除并记录原因，不能承诺每篇都能自动确认。模型接口错误会停止任务，不伪装成机构不合格。

有仓库链接不等于许可证允许开源，也不等于代码完整可复现。本工具暂不核验许可证与运行效果，因此 `required` 只是“有仓库链接”的要求。机构排名无法证明论文不是水文或 AI 生成；内容评估仍关注具体方法、实验对照和证据，不给出未经验证的“AI 文”定性。
