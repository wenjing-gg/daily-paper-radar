# 飞书效果截图

请把最终截图保存在本目录，不需要放原始截图或聊天记录导出文件。

| 文件名 | 建议截图内容 |
| --- | --- |
| `feishu-digest-zh.png` | 中文日报：卡片标题、日期、候选统计和第一篇论文 |
| `feishu-digest-en.png` | 英文日报：相同区域，便于对比语言效果 |

建议使用 PNG，保留清晰文字，宽度约 1000–1600 像素。裁掉无关聊天、侧边栏、群成员姓名、头像、公司信息、内部地址及个人研究方向。不要截机器人配置页、密钥、Webhook 或访问令牌。

截图必须来自实际运行；排版样例不得标成真实送达记录。README 已引用中文日报截图；新增截图时只引用已存在的文件。最终截图进入公开发布包，上传前请确认可公开。
